# AUTHENTICATION FLOW

Firebase Authentication

Backend never trusts frontend role.

For every request:

1. Receive Firebase JWT
2. Verify JWT
3. Extract uid
4. Fetch user
5. Fetch memberships
6. Apply RBAC

# PERFORMANCE RULES

Never fetch entire collections.

Always paginate.

Default page size:

20

Maximum page size:

100

---

# SECURITY RULES

No role stored in frontend state is trusted.

No organizationId received from frontend is trusted.

All organization access verified server side.

Every database query must be scoped.

No wildcard data access allowed.
