## 2. Final Project Representation

Decision

Do NOT create separate collection.

Final Project is a special assignment.

Schema:

{
...
isFinalProject: true
}

Example

Assignment 1

{
title: "Landing Page Clone",
isRequired: true,
isFinalProject: false
}

Assignment 2

{
title: "Portfolio Website",
isRequired: true,
isFinalProject: false
}

Assignment 3

{
title: "Capstone Project",
isRequired: true,
isFinalProject: true
}

---

Benefits

Single review workflow

Single evaluator workflow

Single submission workflow

Single analytics model

No duplicate infrastructure

## Final Project Approval Logic

Certificate Eligibility:

Find assignment where:

isFinalProject = true

Verify:

submission.status = approved

If not approved:

certificate generation blocked

## Updated Certificate Eligibility Rule

Certificate generation allowed only when:

1. Organization Status

active OR archived

AND

2. Enrollment Status

completed

AND

3. All Required Assignments Approved

AND

4. All Required Final Projects Approved

AND

5. Payment Status

success

AND

6. No Existing Active Certificate

for same student + batch

---

FINAL DECISION

Use:

assignments

for curriculum.

Use:

batch_assignments

for mentor/evaluator allocation.

Use:

submissions.assignmentId

to connect student work to curriculum.

No additional final_projects collection required.
