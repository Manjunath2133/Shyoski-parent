# HARD DATABASE RULES

1. Never store passwords.
2. Never trust frontend roles.
3. Never hard delete certificates.
4. Never hard delete payments.
5. Never query cross-organization data.
6. Every major collection must contain organizationId.
7. Every collection must have createdAt.
8. Every update must have updatedAt.
9. Every critical action must create audit log.
10. Every public certificate must be verifiable without login.

---

# SHYOSKI SCALE TARGET

Organizations: 1,000+

Students: 100,000+

Certificates: 1,000,000+

Payments: 500,000+

Audit Logs: 10,000,000+
