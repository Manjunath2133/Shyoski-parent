# SHYOSKI V2.8 CERTIFICATE GOVERNANCE & VALIDITY SPECIFICATION

# CERTIFICATE PHILOSOPHY

A certificate is a permanent achievement record issued jointly by:

1. Shyoski
2. Partner Organization

Certificates must be:

* Verifiable
* Traceable
* Revocable
* Immutable
* Globally Unique

A certificate must never depend on a student account remaining active.

# NON-NEGOTIABLE RULES

1. Certificate numbers are globally unique.
2. Certificates cannot be deleted.
3. Certificates remain verifiable forever.
4. Revoked certificates remain visible.
5. Historical certificates survive organization termination.
6. Verification is public.
7. QR code always points to verification page.
8. Every certificate stores immutable snapshot data.
9. Every certificate action creates audit logs.
10. Certificate authenticity must never depend on frontend data.
